آخرین به‌روزرسانی: ۱۴۰۵/۰۹/۰۵ (۲۶ نوامبر ۲۰۲۶)

## هدف
تحلیل‌گر هوشمند بازار سرمایه ایران: تحلیل بازار و نماد، داده تکنیکال و بنیادی، اخبار و اطلاعیه‌ها، جمع‌بندی با دلایل و ریسک‌ها.

## خارج از دامنه فعلی
ثبت معاملات، مدیریت سبد شخصی، بهای تمام‌شده و سود/زیان شخصی، ورود از Excel، سفارش خودکار — مگر با تصمیم صریح بعدی مالک.

## معماری کلان
- Android: Kotlin، Jetpack Compose، Retrofit
- Backend: Python/Flask، pytest
- بازار: TSETMC
- صورت‌های مالی: Codal (روی main: parser آفلاین؛ کلاینت HTTP در main تأیید نشد)
