2. PRODUCT DEFINITION
SahamYar is an intelligent analysis assistant for the Iranian capital market.
Its scope includes market and instrument analysis, technical and fundamental
data, news and disclosures, and reasoned analytical opinions with risks.

Personal portfolio management, transaction recording, cost basis,
personal profit/loss, Excel transaction imports and automatic trading
are explicitly outside the confirmed scope.

4. ARCHITECTURE
Android: Kotlin, Jetpack Compose, Retrofit.
Backend: Python and Flask.
Market provider: TSETMC.
Financial disclosures: Codal client and parser.
Tests: pytest.

Do not assume FastAPI, PostgreSQL, Redis, or a completed authentication
system unless verified in the current source tree.

5. INSTRUMENT COVERAGE
COMMON_STOCK, RIGHTS, FUND, DEBT and OTHER must be distinguished.
Search coverage and analytical support are separate capabilities.
Unsupported instruments must be reported transparently.

6. DATA QUALITY
Missing values must never be silently converted to zero.
Distinguish AVAILABLE, PARTIAL, UNAVAILABLE, INSUFFICIENT_DATA,
UNSUPPORTED and ERROR.
Separate provider facts, deterministic calculations and AI interpretation.
Cached values must be labeled with their timestamps.

7. CODE AUDIT NOTES
Codal:
- Review retry handling; permanent HTTP errors such as 404 should not
  be retried as transient failures.
- Apply response-size limits before unbounded content is loaded.
- Validate dates and report metadata.
- Keep ambiguous metric mappings explicit rather than guessing.
- Sanitize API errors and avoid exposing internal exception details.

TSETMC:
- Preserve instrument category coverage.
- Retry only transient failures.
- Review client lifecycle, input validation and response-size limits.

Technical analysis:
- Do not report an indicator as available without enough historical data.
- Keep raw, closing and adjusted prices distinct.
- An individual indicator is not a guaranteed trading signal.

Scheduler:
- Avoid import-time startup side effects.
- Review worker lifecycle and shared state before separating processes.
